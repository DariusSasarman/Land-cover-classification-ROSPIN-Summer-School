
This is the ".env" file structure you might need add in webserver/backend for the backend to work:

```env
JWT_SECRET_KEY=
JWT_ALGORITHM=
ACCESS_TOKEN_EXPIRE_MINUTES=
COPERNICUS_CLIENT_ID=
COPERNICUS_CLIENT_SECRET=
GEMINI_API_KEY=
GEMINI_MODEL=
```

You might need to go to [google ai studio](https://aistudio.google.com/) for the gemini api key.

And to [copernicus](https://shapps.dataspace.copernicus.eu/dashboard/#/) for the Copernicus credentials.

JWT and the other stuff is just for credentials and stuff.
